# GDPR Checklista för Testdata

## ✅ Innan testning:
- [ ] Identifiera känslig data
- [ ] Anonymisera eller maskera data
- [ ] Ta bort onödiga personuppgifter
- [ ] Dokumentera datahantering

## 🔒 Under testning:
- [ ] Använd endast säker testdata
- [ ] Logga inte känslig information
- [ ] Säkerställ att testmiljön är isolerad

## 📊 Efter testning:
- [ ] Rensa temporära filer
- [ ] Dokumentera testresultat
- [ ] Arkivera endast anonymiserad data
